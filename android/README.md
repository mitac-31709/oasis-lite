# Oasis Lite（Android）使い方

povo Data Oasis を、公式 shop の重いページを読まずにチャージするアプリです。  
**初回だけ povo アプリ経由でログインし、以降は「データ取得」だけで使えます。**

アプリ内の **使い方** にも同じ内容があります。  
1〜2章を初回に読めば足り、あとは必要なときだけ見てください。

---

## 流れの全体像

| 回 | やること |
| --- | --- |
| **初回** | povo の Data Oasis バナー → このアプリで開く → データ取得 |
| **2回目以降** | Oasis Lite を開く → **データ取得** |

残データ量や利用回数は公式 povo アプリで確認してください（通信量を抑えるため、ここでは取りません）。

---

## インストール時に一度だけ

1. APK を入れる（例: `app/build/outputs/apk/debug/app-debug.apk`）
2. アプリを起動する
3. 初回ダイアログ、または上部の **既定** から設定を開く
4. **サポートされているリンク** で **`shop.povo.jp` / `dashboard`** をオン

これで Data Oasis の SSO リンク（`shop.povo.jp/dashboard/...`）が Oasis Lite に渡ります。  
それ以外の shop リンクは、既定のブラウザで開きます。

位置情報は、初回の「データ取得」時に求められたら許可してください。

---

## 初回: povo からログインする

目的: 使い切りの SSO URL（`token` + `sso=true`）で Auth0 にログインし、トークンを残す。

1. **povo 2.0** を開く
2. **Data Oasis** のバナーをタップする
3. 「ブラウザで開く」／共有で **Oasis Lite** を選ぶ  
   （または URL をコピーし、上部欄に貼って **開く**）
4. **データ取得** を押す（SSO URL 付きなら自動で始まることもあります）
5. 認証・位置情報・データ取得がすべて緑になれば成功

### うまくいかないとき

- リンクが既定になっていない → **既定** からオンにする
- 別ブラウザで開いてしまった → URL をコピーして上部欄へ
- 認証が赤 → SSO は使い切りが多いです。povo からバナーを開き直す

---

## 2回目以降: ボタンだけで取る

1. **Oasis Lite** を起動する（URL 欄は空でよい）
2. **データ取得** を押す
3. 認証 → 位置情報 → データ取得、の順に緑になれば完了

次のときは、初回と同じく povo のバナーから開き直してください。

- 認証が「失敗」（例: `login_required`）
- アプリのデータ消去・再インストール後
- 長く放置してセッションが切れたとき

トークンの目安は約1時間です。切れても、サイレント認証が通れば URL なしで続けられることがあります。

## 画面の見方

### 上部バー

| 要素 | 意味 |
| --- | --- |
| URL 欄 | SSO URL の表示・貼り付け |
| 開く | その URL で読み直す |
| 既定 | Data Oasis リンクをこのアプリで開く設定へ |

### メイン画面

| 要素 | 意味 |
| --- | --- |
| データ取得 | 認証〜claim をまとめて実行 |
| 使い方 | 手順のモーダル |
| 認証 / 位置情報 / データ取得 | 灰・黄・緑・赤の状態 |
| 一言メッセージ | いま何をしているか |
| デバッグログ | 折りたたみ。詳細ログ（コピー可） |

---

## チャージの前提（公式どおり）

- 対象スポット（ローソン・対象駅など）にいる
- 位置情報が許可されている
- 回数制限内（目安: 1日1回 / 月10回）

場所が違うと `Location Limit` などで拒否されます。

---

## ビルド（開発者向け）

```bat
cd tasks\2026-08-11-povo-oasis-lite\android
gradlew.bat assembleRelease
```

リリース APK: `app\build\outputs\apk\release\OasisLite.apk`（目安 30–60 KB）  
デバッグ: `gradlew.bat assembleDebug`

素の `Activity` + システム WebView のみです。
